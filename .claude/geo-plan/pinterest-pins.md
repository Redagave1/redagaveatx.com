## How to add more pins

Source photos: JPEG, 1200 px or wider. Pin tool: https://www.pinterest.com/pin-creation-tool/

1. Upload a board's files together through the hidden "File Upload" input (find it again before every upload; the reference goes stale after a publish).
2. Drafts keep no file names. Crop each file a few pixels differently so each 736-wide thumbnail has its own height (keep them 7 or more apart), and match drafts by that height. Read the draft order after the upload; it is not the upload order.
3. Per pin: click the first draft, type title, Tab, description, Tab, link, Tab, Return to open the board list, type the board name, wait, Tab, Tab, Return. Pick the board on every pin: a draft keeps the board that was used last.
4. Check before Publish: title, link, board name, and the titled draft's thumbnail height. Then click Publish once and wait up to 45 seconds for the draft count to drop. Never click Publish a second time: a slow publish plus a second click sent the next draft out with no title (round 2, fixed by editing that pin).
5. First pin of a new board: Tab, Tab lands on "Create board"; Return opens a dialog with the name filled in; click Create.
6. If a board made a minute ago is missing from the board list, close the list with Escape and reload the pin tool. Drafts and their text are kept. Never click Create a second time.
7. Five or six pins fit in one batch of browser steps. To fix a published pin, open it, use the three-dot menu, Edit Pin.
